
## qg rm 删除分支命令（2026-11-08 完成）

- 用户新需求 + 选型：`qg rm [branch]`，`-o/--origin` 连远程分支一起删（push origin --delete），命令名 rm。
- `internal/git/rm.go`：porcelain 首条为主工作树；分支检出于主仓库→先切默认分支（defaultLocalBranch 排除自身，优先 main 后 master）；链接工作树→git worktree remove（脏树默认拒绝）；`branch -d` 防未合并丢码，--force 升级 -D + worktree remove --force；远程删除失败仅警告。所有 git 操作在主工作树根执行，shell 站在被删目录也不受影响。
- cmd/cmt/rm.go：无参数删当前分支；-o 时 y/N 确认；cmd/cmt/root.go 注册。
